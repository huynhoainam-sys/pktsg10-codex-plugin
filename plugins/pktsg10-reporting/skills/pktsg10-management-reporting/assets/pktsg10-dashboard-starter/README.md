# Pktsg10 Dashboard Starter

1. Create a bound Apps Script project from the target Google Sheet.
2. Add `Code.gs`, `Index.html`, and `appsscript.json`.
3. Create a `DASH_DATA` tab whose first row is the header.
4. Deploy the Web App with the appropriate audience and review authorization.
5. Test totals, refresh, stale/error state, permissions and mobile layout.

The starter uses 60-second polling and CacheService. It is near-real-time, not a WebSocket.
