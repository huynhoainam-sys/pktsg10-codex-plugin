# Brief Routing Matrix

| Brief của người dùng | Primary | Supporting | Exit gate |
|---|---|---|---|
| Phân tích doanh số/KPI chi nhánh | FPT Telecom | validate-data | KPI reconciled |
| Chỉnh màu/font/bố cục Sheet | Report design | Google Sheets | design consistent |
| Sửa công thức/filter/ảnh/link | Google Sheets | Report design | sheet reloaded |
| Dashboard sales/kỹ thuật/CSKH | FPT Telecom | Report design + visualize-data | decision readable |
| Kế hoạch marketing địa bàn | FPT Telecom | marketing-plan | owner/KPI/kill criteria |
| Funnel lead → lắp thành công | FPT Telecom | funnel-analysis | stage definitions verified |
| Churn/khiếu nại/repeat fault | FPT Telecom | customer-feedback-analysis + churn-prevention | root causes evidenced |
| Báo cáo giám đốc hoàn chỉnh | FPT Telecom | Report design + Sheets + validate-data | actionable handoff |

When the user explicitly names a skill, keep it as Primary. Supporting skills are limited to the current phase and should not be activated unnecessarily.
